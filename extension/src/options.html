Raw data pages

What happens when a tab shows a JSON, XML, YAML or CSV file as plain text, such as an API response.

Popup

Offer what I just copied
Opening the popup shows the JSON, YAML, CSV or log on your clipboard, ready to open with Enter. Chrome asks to let lint.one read the clipboard; it is read only while the popup is open.
Remember what I open, until Chrome closes
The last few files, in memory only, so the popup can open them again. Nothing is written to disk.

Toolbar icon

Mark files lint.one can open
On a page like /users.json or /report.csv, the icon carries the format's colour. It goes by the address alone and needs no access to the page.
